# Sample documents

Markdown files for trying the editor by hand. Open any of them, switch to Markdown Live Editor,
and edit freely. Nothing automated reads this folder: the tests have their own purpose-built
documents in `test/fixtures/`, and a unit test fails if a test or script ever refers to a file
here.

| File | Good for |
| --- | --- |
| `TestTable.md` | A quick look at prose, lists and two small tables |
| `standard-markdown.md` | A broad tour of Markdown in one document |
| `standard-markdown-in-table.md` | The same kinds of content inside table cells |
| `html-in-markdown-table.md` | Inline HTML inside table cells |
| `column-sizing-algorithm.md` | How columns share width as content grows |
| `wide-table.md` | Horizontal scrolling in a table wider than the window |
| `task-checkboxes.md` | Checked and unchecked task items |
